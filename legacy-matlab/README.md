These MATLAB helper scripts are legacy leftovers from the earlier, MATLAB-dependent version of the requirement checker.

You do NOT need them for the Windows-only PowerShell + HTML dashboard experience. Keep them for reference only, or delete them
if you just want the Windows tools:
- requirements_checker.ps1 / requirements_dashboard.ps1 (current Windows flow)
- requirements_checker.cmd / start_dashboard.cmd (double-click launchers)

Files in this folder remain untouched by the Windows packaging script so they are harder to click by accident.
