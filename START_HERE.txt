START HERE (Windows 11, no MATLAB needed)
-----------------------------------------

1) Double-click **start_dashboard.cmd**
   - Browser opens. Hit **Scan all**.

   Prefer text only? Double-click **requirements_checker.cmd**, press **A + Enter**.

2) Let it fix things
   - Missing stuff? The app tries a silent **winget** install first.
   - If winget isn’t there, it offers the official download page.

3) Share it
   - In PowerShell, run `./package_windows_checker.ps1` to create a zip with both launchers + this file.
