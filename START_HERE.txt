QUICK STEPS (Windows 11, no MATLAB needed)
-----------------------------------------

1) Launch it
   - Double-click **start_dashboard.cmd** for the browser dashboard (checks for PowerShell first), OR
   - Double-click **requirements_checker.cmd** for the menu version.

2) Run the checks
   - Dashboard: hit **Scan all**. Cards for Windows, MATLAB, Java, .NET, compiler, internet, disk, and memory update live.
   - Menu: press **A + Enter** to scan everything, or pick a number. If something is missing, choose **Y** to open the download page.

3) Silent mode (optional)
   powershell -ExecutionPolicy Bypass -File requirements_checker.ps1 -ScanAll

4) Make a zip to share (optional)
   ./package_windows_checker.ps1
   This creates requirements-checker-windows.zip with both launchers and these instructions.
